# MAKO アシスタント — 機能紹介

[English](en.md) · [台灣正體中文](zh_TW.md) · [简体中文](zh_CN.md) · **日本語** · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Italiano](it.md) · [ไทย](th.md) · [Tiếng Việt](vi.md) · [Bahasa Melayu](ms.md) · [हिन्दी](hi.md)

**MAKO アシスタント**は、設定ファイルを手で編集しなくても、Steam ゲームの **MAKO Renderer フレーム生成（Mako FG）** をワンクリックでオン／オフできる Linux デスクトップ向けの GUI ツールです。

## 対象ユーザー

Steam Deck のゲームモードでは、MAKO の Decky プラグインを使ってゲーム中に設定できます。しかし**一般的な Linux のデスクトップ PC やノート PC**（Arch、Fedora、Ubuntu などで KDE Plasma や GNOME を使用）では、ゲームで MAKO を使うために、ふつうは次の作業を手で行う必要があります。

1. Steam の「プロパティ → 起動オプション」に `~/.local/bin/mako-launch %command%` を追加する。既存のオプションを壊さないように注意が必要です。
2. ゲームが**実際に実行する**プログラム名を調べる（多くのゲームは先にランチャーを起動し、Unreal Engine のゲームは `*-Shipping.exe` を実行します）。
3. MAKO の設定でゲーム用プロファイルを作り、正しい対象プロセス（`active_in`）を入力する。
4. ゲームのアップデートで実行ファイルのパスや名前が変わったら、すべてやり直す。
5. ゲームを起動しても、フレーム生成が本当に動いているのか分からない。

MAKO アシスタントはこれらの作業をボタンひとつにまとめ、ゲームの実行中は MAKO が**実際に**有効にしている機能を表示します。

## 使う前に必要な準備

> ⚠ **MAKO アシスタントには MAKO Renderer は含まれておらず、インストールも行いません。** MAKO の設定を管理するだけのツールです。

先に次の作業を済ませてください。

1. **MAKO Renderer（スタンドアロン版）をインストールする。** MAKO 自身のインストール手順に従ってください。インストール後に `~/.local/bin/mako-launch` があれば完了です。
2. **MAKO UI を一度開いて**既定の設定を作成する。これで `~/.config/mako-render/conf.toml` と既定プロファイル `mako` が作られます。MAKO アシスタントが作るゲーム用プロファイルは、すべてこの既定プロファイルをもとにします。
3. **Steam をインストールする。** ネイティブ版（`~/.local/share/Steam`、`~/.steam`）、Flatpak 版、Snap 版に対応しています。

上記がすべて完了し、MAKO 自体が正しく動作することを確認してから、MAKO アシスタントでゲームに Mako FG を導入してください。

任意：**Decky Loader**。導入すると、Steam を終了しなくても実行中の Steam に起動オプションを即時反映できます（下の「起動オプションの書き込み方法」を参照）。

## 機能

### 1. Steam ライブラリの自動スキャン

- 初回起動時に**すべての** Steam ライブラリ（別ドライブのライブラリも含む）を自動でスキャンします。その後は「⟳ Steam ゲーム一覧を再スキャン」で再スキャンできます。
- Proton や Steam Linux Runtime などのツールは除外され、ゲームだけが表示されます。
- ゲーム名は UI の言語に合わせて Steam 公式のローカライズ名（例：「ウィッチャー３」）で表示され、その言語の慣習に従って並びます。
- 各ゲームにはカバー画像、現在の起動オプション、MAKO プロファイル、検出したゲーム実行ファイルのパスが表示されます。

### 2. ワンクリックで「Mako FG を導入」

「Mako FG を導入」をクリックすると、次の処理を行います。

- **起動オプションを追加**：Steam の起動オプションに `~/.local/bin/mako-launch %command%` を追加し、**既存の設定はそのまま残します**。たとえば `FOO=1 %command% -dx11` は `FOO=1 ~/.local/bin/mako-launch %command% -dx11` になります。
- **本当のゲーム実行ファイルを検出**：Steam のアプリ情報から判断します。ランチャー（インストールフォルダ内の実際のゲームプログラムを探します）や Unreal Engine の `*-Shipping.exe` に対応し、よくある補助プログラムは除外します。
- **MAKO のゲーム用プロファイルを作成**：既定プロファイル `mako` をもとに、`conf.toml` にそのゲーム専用のプロファイルを作り、MAKO のプロファイルメタデータを書き込みます。**このプロファイルは MAKO UI と Decky プラグインの両方から見え、直接編集もできます。**
- **重複マッチを防止**：既定プロファイル `mako` もこのゲームの実行ファイルを対象にしている場合は、`mako` から外し、ゲームが自分のプロファイルだけを使うようにします。別のゲームのプロファイルが同じ実行ファイルを対象にしている場合は警告を表示しますが、自動では変更しません。

### 3. 起動オプションの書き込み方法

Steam は起動オプションを起動時にしか読み込まず、終了時に設定ファイルを上書きします。変更が Steam に上書きされないよう、MAKO アシスタントは Steam の状態に応じて書き込み方法を自動で選び、その状態をウィンドウに表示します。

| Steam の状態 | 書き込み方法 |
|---|---|
| 起動していない | Steam の `localconfig.vdf` を直接編集（事前にバックアップ） |
| 起動中で、Steam クライアントに接続できる（Decky Loader が必要） | Steam クライアント経由で即時反映。Steam の再起動は不要 |
| 起動中だが接続できない | Steam を終了してよいか確認 → 変更を反映 → Steam を自動で再起動 |

### 4. 削除

- 「削除」は起動オプションから `mako-launch` を取り除くだけで、ほかのオプションはそのまま残します。
- そのゲームの MAKO 設定は**既定で残ります**。あとで再導入するときにそのまま使えます。「MAKO Renderer のゲーム設定も削除する」にチェックを入れると、設定も一緒に削除されます。

### 5. 既存設定の取り込み

以前に手で `mako-launch` を追加したゲームには「設定を取り込む」ボタンが表示されます。クリックすると、そのゲームの MAKO プロファイルを作成し、以降のパス自動更新の対象に加えます。

### 6. ゲームのアップデート後にパスを自動更新

- 再スキャンのたびに、**このツールで導入した**ゲームの実行ファイルを検出し直します。アップデートで実行ファイルの場所や名前が変わっていれば MAKO の対象プロセスを自動で更新し、変更内容をログ欄に表示します。
- MAKO UI で**手動で追加した**対象プロセスは残ります。
- MAKO UI でゲームのプロファイルを削除した場合は、その判断を尊重し、自動で作り直すことはありません。
- ライブラリが一時的にオフライン（外付けドライブが未接続など）のときは、そのゲームの設定は変更しません。

### 7. 一覧から直接ゲームを起動

各行の「▶ 起動」ボタンで、Steam 経由でゲームを起動できます。ゲームの実行中、ボタンには「実行中」と表示されます。

### 8. 実際に有効な MAKO 機能をリアルタイム表示

「実行中の MAKO 機能」列は 3 秒ごとに更新されます。表示されるのは設定ファイルの内容ではなく、MAKO がゲーム内で**実際に適用している**状態です。

- **フレーム生成**：固定倍率（例：×2）またはアダプティブ（目標 FPS・最大倍率）、Flow スケール、パフォーマンスモード。
- **スケーリング**：スケーリング方式と解像度（例：1280×720 → 2560×1440）、スーパーサンプリング。
- **その他のレイヤー**：vkBasalt、Zink、ALSA オーディオ。
- **未適用の変更**：「ゲームの再起動が必要」「スワップチェーンの再作成が必要」など。MAKO が報告したエラーも表示します。

Mako FG を導入したのに MAKO が実際には読み込まれていないゲームもそのことが表示されるので、問題の切り分けに役立ちます。

### 9. ゲーム起動時のオーバーレイ

MAKO アシスタントを開いたままゲームを起動すると、ゲーム内で MAKO が動作し始めたことを検出した時点で、画面右下に有効な MAKO 機能を約 10 秒表示してからフェードアウトします。

- 表示は起動 1 回につき 1 度だけで、キーボードやマウスのフォーカスを奪わず、マウス操作もそのまま通します。
- フルスクリーンの Proton ゲームの上にも表示できます。
- Mako FG を導入したゲームが起動から 90 秒たっても MAKO を読み込まない場合は、代わりに警告を表示します。
- ツールバーの「起動時オーバーレイ」チェックボックスでオフにできます。

### 10. 検索と絞り込み

- ゲーム名（どの言語の名前でも可）または App ID で検索できます。
- 絞り込み：すべてのゲーム、Mako FG 導入済み、Mako FG 未導入、MAKO 設定のみ、実行中。

### 11. 12 の表示言語

台灣正體中文、简体中文、English、日本語、Deutsch、Français、Español、Italiano、ไทย、Tiếng Việt、Bahasa Melayu、हिन्दी。

初回起動時はシステムの言語に合わせて自動で選ばれます。右上でいつでも切り替えられ、すぐに反映されて次回以降も記憶されます。

### 12. 安全への配慮

- `conf.toml` と Steam の `localconfig.vdf` は、変更前に必ずバックアップ（`*.mako-assistant.bak`）を取ります。
- `conf.toml` を書き込んだあと `mako-cli validate` で検証し、MAKO が受け付けなければ自動で元に戻します。
- Steam の起動中に `localconfig.vdf` を直接編集することはありません。
- 「Mako FG を導入」をクリックすると、まず MAKO Renderer がインストール済み（`~/.local/bin/mako-launch` がある）で、MAKO UI が設定を作成済みかを確認します。どちらかが欠けていれば何も変更せず、先に MAKO をインストールするよう案内します。

## MAKO アシスタントのインストール

**AppImage（推奨）**：Python と Qt を同梱しているので、ほかに何もインストールする必要はありません。

1. [Releases](https://github.com/mosesmoon/mako-assistant/releases) ページから `MAKO_Assistant-<バージョン>-x86_64.AppImage` をダウンロードします。
2. 実行可能にします：ファイルを右クリック →「プロパティ」→「アクセス権」で「プログラムとして実行可能」をオンにします（表記はファイルマネージャーによって異なります）。
3. ダブルクリックすると MAKO アシスタントが開きます。

ターミナルから実行することもできます：

```bash
chmod +x MAKO_Assistant-*-x86_64.AppImage
./MAKO_Assistant-*-x86_64.AppImage
```

起動しない場合は、システムに FUSE がない可能性があります。代わりに `./MAKO_Assistant-*-x86_64.AppImage --appimage-extract-and-run` で実行してください。

**ソースから実行**：Python 3.11 以降と PyQt6 が必要です（Arch：`sudo pacman -S python-pyqt6`）。

```bash
./mako-assistant    # そのまま実行
./install.sh        # ~/.local/share/mako-assistant にインストールし、アプリケーションメニューに登録
```

## 既知の制限

- **Steam Deck のゲームモード（gamescope）ではオーバーレイは表示されません。** Steam Deck では MAKO の Decky プラグインをお使いください。
- ネイティブ Wayland の排他フルスクリーンで動作するゲームでは、オーバーレイが隠れることがあります。
- 起動オプションの即時反映は、Decky Loader が開く Steam クライアントのポート（8080）経由でのみ動作します。Decky がない場合は、Steam を終了してから反映するか、ツールに Steam の終了と再起動を任せてください。
- 「実際に有効な機能」と MAKO のプロファイルメタデータは、現行の MAKO のファイル形式に合わせて読み取っています。MAKO や Steam の大型アップデート後は一時的に表示されない（「—」と表示される）ことがありますが、導入と削除は引き続き動作します。
- タイ語、ベトナム語、マレー語、ヒンディー語では、右クリックメニューが英語になります（Qt にこれらの言語の公式翻訳がないため）。Steam にはマレー語とヒンディー語のゲーム名がないため、この 2 言語では常に元のゲーム名を表示します。
- バックアップは最新の 1 世代だけ保持します。

## データの保存場所

| 場所 | 内容 |
|---|---|
| `~/.config/mako-assistant/state.json` | MAKO アシスタント自身の状態：ゲーム一覧のキャッシュ、このツールで導入したゲーム、表示言語、オーバーレイの設定 |
| `~/.config/mako-render/conf.toml` | MAKO Renderer の設定（各ゲームのプロファイル） |
| `~/.config/mako-render/profile-metadata.json` | MAKO プロファイルのメタデータ（ゲーム名、Steam App ID） |
| `<Steam>/userdata/<ユーザー ID>/config/localconfig.vdf` | Steam の起動オプション |
