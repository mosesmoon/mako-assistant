# ผู้ช่วย MAKO — แนะนำฟีเจอร์

[English](en.md) · [台灣正體中文](zh_TW.md) · [简体中文](zh_CN.md) · [日本語](ja.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Italiano](it.md) · **ไทย** · [Tiếng Việt](vi.md) · [Bahasa Melayu](ms.md) · [हिन्दी](hi.md)

**ผู้ช่วย MAKO** เป็นเครื่องมือแบบกราฟิกสำหรับเดสก์ท็อป Linux ที่ช่วยเปิดหรือปิด **การสร้างเฟรมของ MAKO Renderer (Mako FG)** ให้เกม Steam ได้ในคลิกเดียว โดยไม่ต้องแก้ไฟล์ตั้งค่าใด ๆ ด้วยตัวเอง

## เหมาะกับใคร

บน Steam Deck ในโหมดเกม MAKO มีปลั๊กอิน Decky ให้ตั้งค่าได้ระหว่างเล่นเกม แต่ถ้าคุณใช้ **คอมพิวเตอร์เดสก์ท็อปหรือโน้ตบุ๊ก Linux ทั่วไป** (เช่น Arch, Fedora หรือ Ubuntu กับ KDE Plasma หรือ GNOME) การจะให้เกมใช้ MAKO ได้ มักต้องทำทุกอย่างต่อไปนี้ด้วยมือ:

1. เพิ่ม `~/.local/bin/mako-launch %command%` ลงในตัวเลือกการเปิดเกมของ Steam (คุณสมบัติ → ตัวเลือกการเปิด) โดยไม่ทำให้ตัวเลือกเดิมเสีย
2. หาชื่อโปรแกรมที่เกม **รันจริง** (หลายเกมเปิดตัวเปิดเกม (launcher) ก่อน ส่วนเกม Unreal Engine จะรัน `*-Shipping.exe`)
3. สร้างโปรไฟล์เกมในการตั้งค่าของ MAKO แล้วใส่โปรเซสที่จับคู่ (`active_in`) ให้ถูกต้อง
4. ทำทั้งหมดใหม่อีกครั้งเมื่ออัปเดตเกมแล้วพาธหรือชื่อไฟล์เกมเปลี่ยน
5. เปิดเกมแล้วก็ยังไม่แน่ใจว่าการสร้างเฟรมทำงานอยู่จริงหรือไม่

ผู้ช่วย MAKO รวมขั้นตอนเหล่านี้ไว้ในปุ่มเดียว และขณะที่เกมทำงานอยู่ จะบอกว่า MAKO เปิดใช้ฟีเจอร์ใดอยู่ **จริง ๆ**

## สิ่งที่ต้องเตรียมก่อนใช้งาน

> ⚠ **ผู้ช่วย MAKO ไม่ได้รวม MAKO Renderer มาด้วย และจะไม่ติดตั้งให้คุณ** เครื่องมือนี้มีไว้จัดการการตั้งค่าของ MAKO เท่านั้น

โปรดทำสิ่งต่อไปนี้ก่อน:

1. **ติดตั้ง MAKO Renderer (เวอร์ชัน standalone)** ตามคำแนะนำการติดตั้งของ MAKO เอง หลังติดตั้งแล้วควรมีไฟล์ `~/.local/bin/mako-launch`
2. **เปิด MAKO UI หนึ่งครั้ง** เพื่อสร้างการตั้งค่าเริ่มต้น ขั้นตอนนี้จะสร้าง `~/.config/mako-render/conf.toml` และโปรไฟล์เริ่มต้น `mako` โปรไฟล์เกมทุกอันที่ผู้ช่วย MAKO สร้างจะคัดลอกมาจากโปรไฟล์เริ่มต้นนี้
3. **ติดตั้ง Steam** รองรับทั้งแพ็กเกจแบบเนทีฟ (`~/.local/share/Steam`, `~/.steam`) และเวอร์ชัน Flatpak กับ Snap

ตรวจสอบให้แน่ใจว่าทำครบทุกข้อและ MAKO ทำงานได้ปกติแล้ว จึงค่อยใช้ผู้ช่วย MAKO ติดตั้ง Mako FG ให้เกม

ไม่บังคับ: **Decky Loader** ถ้าติดตั้งไว้ จะใช้ตัวเลือกการเปิดเกมได้ทันทีขณะที่ Steam เปิดอยู่ โดยไม่ต้องปิด Steam (ดู "วิธีบันทึกตัวเลือกการเปิดเกม" ด้านล่าง)

## ฟีเจอร์

### 1. สแกนคลังเกม Steam อัตโนมัติ

- เมื่อเปิดครั้งแรก จะสแกนคลังเกม Steam **ทั้งหมด** (รวมถึงคลังเกมในไดรฟ์อื่น) หลังจากนั้นกด "⟳ สแกนรายการเกม Steam ใหม่" ได้
- เครื่องมืออย่าง Proton และ Steam Linux Runtime จะถูกกรองออก แสดงเฉพาะเกม
- ชื่อเกมแสดงเป็นชื่อภาษาท้องถิ่นอย่างเป็นทางการของ Steam ตามภาษาของหน้าจอ และเรียงตามแบบที่ภาษานั้นใช้
- แต่ละเกมแสดงภาพปก ตัวเลือกการเปิดเกมปัจจุบัน โปรไฟล์ MAKO และพาธไฟล์เกมที่ตรวจพบ

### 2. "ติดตั้ง Mako FG" ในคลิกเดียว

เมื่อกด "ติดตั้ง Mako FG" เครื่องมือจะ:

- **เพิ่มตัวเลือกการเปิดเกม** `~/.local/bin/mako-launch %command%` ลงในตัวเลือกการเปิดเกมของ Steam และ **คงค่าเดิมไว้** เช่น `FOO=1 %command% -dx11` จะกลายเป็น `FOO=1 ~/.local/bin/mako-launch %command% -dx11`
- **ตรวจหาไฟล์เกมตัวจริง** จากข้อมูลแอปของ Steam รองรับเกมที่มีตัวเปิดเกม (จะหาโปรแกรมเกมตัวจริงในโฟลเดอร์ที่ติดตั้งแทน) และ `*-Shipping.exe` ของ Unreal Engine และข้ามโปรแกรมช่วยเหลือที่พบบ่อย
- **สร้างโปรไฟล์เกมของ MAKO** โดยคัดลอกโปรไฟล์เริ่มต้น `mako` เป็นโปรไฟล์เฉพาะของเกมใน `conf.toml` และบันทึกเมทาดาทาโปรไฟล์ของ MAKO **ทั้ง MAKO UI และปลั๊กอิน Decky มองเห็นโปรไฟล์นี้และแก้ไขได้โดยตรง**
- **ป้องกันการจับคู่ซ้ำ** ถ้าโปรไฟล์เริ่มต้น `mako` จับคู่กับไฟล์เกมนี้ด้วย จะนำไฟล์นั้นออกจาก `mako` เพื่อให้เกมใช้เฉพาะโปรไฟล์ของตัวเอง ถ้าโปรไฟล์ของเกมอื่นจับคู่กับไฟล์เดียวกัน จะมีคำเตือน แต่จะไม่เปลี่ยนอะไรให้อัตโนมัติ

### 3. วิธีบันทึกตัวเลือกการเปิดเกม

Steam อ่านตัวเลือกการเปิดเกมเฉพาะตอนเริ่มทำงาน และเขียนทับไฟล์ตั้งค่าตอนปิด เพื่อไม่ให้ Steam เขียนทับการเปลี่ยนแปลงของคุณ ผู้ช่วย MAKO จะเลือกวิธีบันทึกตามสถานะของ Steam และแสดงสถานะนั้นในหน้าต่าง:

| สถานะของ Steam | วิธีบันทึก |
|---|---|
| ไม่ได้เปิด | แก้ไฟล์ `localconfig.vdf` ของ Steam โดยตรง (สำรองไฟล์ไว้ก่อน) |
| เปิดอยู่ และเชื่อมต่อกับไคลเอนต์ Steam ได้ (ต้องมี Decky Loader) | ใช้การเปลี่ยนแปลงทันทีผ่านไคลเอนต์ Steam โดยไม่ต้องรีสตาร์ต Steam |
| เปิดอยู่ แต่เชื่อมต่อไม่ได้ | ถามว่าจะปิด Steam หรือไม่ → ใช้การเปลี่ยนแปลง → เปิด Steam ใหม่ |

### 4. ถอดออก

- "ถอดออก" จะนำแค่ `mako-launch` ออกจากตัวเลือกการเปิดเกม ตัวเลือกอื่นยังคงเหมือนเดิม
- การตั้งค่า MAKO ของเกม **จะถูกเก็บไว้เป็นค่าเริ่มต้น** เพื่อใช้ต่อได้ถ้าติดตั้งใหม่ภายหลัง ติ๊ก "ลบการตั้งค่าเกมใน MAKO Renderer ด้วย" ถ้าต้องการลบไปพร้อมกัน

### 5. นำเข้าการตั้งค่าที่มีอยู่

ถ้าคุณเคยเพิ่ม `mako-launch` ให้เกมด้วยมือมาก่อน เกมนั้นจะมีปุ่ม "นำเข้าการตั้งค่า" เมื่อกด เครื่องมือจะสร้างโปรไฟล์ MAKO ให้เกม และนับรวมเกมนั้นในการอัปเดตพาธอัตโนมัติต่อจากนี้

### 6. อัปเดตพาธอัตโนมัติหลังอัปเดตเกม

- ทุกครั้งที่สแกนใหม่ เครื่องมือจะตรวจหาไฟล์เกมของเกมที่ **ติดตั้งผ่านเครื่องมือนี้** อีกครั้ง ถ้าอัปเดตเกมแล้วไฟล์ย้ายที่หรือเปลี่ยนชื่อ จะอัปเดตโปรเซสที่จับคู่ใน MAKO ให้อัตโนมัติ และแสดงการเปลี่ยนแปลงในช่องบันทึก
- โปรเซสที่คุณ **เพิ่มเองด้วยมือ** ใน MAKO UI จะถูกเก็บไว้
- ถ้าคุณลบโปรไฟล์ของเกมใน MAKO UI เครื่องมือจะเคารพการตัดสินใจนั้นและไม่สร้างใหม่ให้
- ถ้าคลังเกมออฟไลน์ชั่วคราว (เช่น ไดรฟ์ภายนอกที่ไม่ได้เสียบ) การตั้งค่าของเกมเหล่านั้นจะไม่เปลี่ยน

### 7. เปิดเกมจากรายการได้ทันที

ทุกแถวมีปุ่ม "▶ เปิดเกม" ที่เปิดเกมผ่าน Steam ขณะที่เกมทำงานอยู่ ปุ่มจะแสดง "กำลังทำงาน"

### 8. แสดงฟีเจอร์ MAKO ที่ใช้งานจริงแบบเรียลไทม์

คอลัมน์ "ฟีเจอร์ MAKO ที่ทำงานอยู่" อัปเดตทุก 3 วินาที และแสดงสิ่งที่ MAKO **ใช้งานจริง** ในเกม ไม่ใช่สิ่งที่เขียนไว้ในไฟล์ตั้งค่า:

- **การสร้างเฟรม**: ตัวคูณคงที่ (เช่น ×2) หรือโหมดปรับอัตโนมัติ (FPS เป้าหมายและตัวคูณสูงสุด) สเกล Flow และโหมดประสิทธิภาพ
- **การปรับขนาดภาพ**: วิธีปรับขนาดและความละเอียด (เช่น 1280×720 → 2560×1440) และซูเปอร์แซมปลิง
- **เลเยอร์อื่น ๆ**: vkBasalt, Zink, เสียง ALSA
- **การเปลี่ยนแปลงที่รอใช้งาน** เช่น "ต้องรีสตาร์ตเกม" หรือ "ต้องสร้าง swapchain ใหม่" รวมถึงข้อผิดพลาดที่ MAKO รายงาน

ถ้าเกมติดตั้ง Mako FG แล้วแต่ MAKO ไม่ได้โหลดจริง ก็จะแสดงให้เห็นด้วย ช่วยให้หาสาเหตุของปัญหาได้ง่ายขึ้น

### 9. การแสดงซ้อนตอนเปิดเกม

ถ้าผู้ช่วย MAKO เปิดอยู่ตอนที่คุณเปิดเกม ทันทีที่ตรวจพบว่า MAKO ทำงานในเกมแล้ว จะแสดงฟีเจอร์ MAKO ที่ใช้งานอยู่ที่มุมขวาล่างของจอประมาณ 10 วินาที แล้วค่อย ๆ จางหายไป:

- แสดงครั้งเดียวต่อการเปิดเกมหนึ่งครั้ง ไม่แย่งโฟกัสคีย์บอร์ดหรือเมาส์ และคลิกเมาส์ทะลุผ่านได้
- แสดงทับเกม Proton แบบเต็มจอได้
- ถ้าเกมที่ติดตั้ง Mako FG ยังไม่โหลด MAKO หลังเปิดไปแล้ว 90 วินาที จะแสดงคำเตือนแทน
- ปิดได้ด้วยช่องทำเครื่องหมาย "แสดงซ้อนตอนเปิดเกม" บนแถบเครื่องมือ

### 10. ค้นหาและตัวกรอง

- ค้นหาด้วยชื่อเกม (ภาษาใดก็ได้) หรือ App ID
- ตัวกรอง: เกมทั้งหมด, ติดตั้ง Mako FG แล้ว, ยังไม่ได้ติดตั้ง Mako FG, มีเฉพาะการตั้งค่า MAKO, กำลังทำงาน

### 12. ออกแบบมาให้ปลอดภัย

- สำรอง `conf.toml` และ `localconfig.vdf` ของ Steam (`*.mako-assistant.bak`) ไว้ก่อนแก้ไขทุกครั้ง
- หลังบันทึก `conf.toml` เครื่องมือจะตรวจด้วย `mako-cli validate` ถ้า MAKO ไม่ยอมรับ จะกู้คืนไฟล์เดิมให้อัตโนมัติ
- จะไม่แก้ `localconfig.vdf` โดยตรงขณะที่ Steam เปิดอยู่
- เมื่อกด "ติดตั้ง Mako FG" เครื่องมือจะตรวจก่อนว่าติดตั้ง MAKO Renderer แล้ว (มีไฟล์ `~/.local/bin/mako-launch`) และ MAKO UI สร้างการตั้งค่าไว้แล้ว ถ้าขาดอย่างใดอย่างหนึ่ง จะไม่เปลี่ยนแปลงอะไรเลย และแจ้งให้ติดตั้ง MAKO ก่อน

## ติดตั้งผู้ช่วย MAKO

**AppImage (แนะนำ)**: มี Python และ Qt มาในตัว ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
chmod +x MAKO_Assistant-*-x86_64.AppImage
./MAKO_Assistant-*-x86_64.AppImage
```

**รันจากซอร์สโค้ด**: ต้องใช้ Python 3.11 ขึ้นไปและ PyQt6 (Arch: `sudo pacman -S python-pyqt6`)

```bash
./mako-assistant    # รันโดยตรง
./install.sh        # ติดตั้งไปที่ ~/.local/share/mako-assistant และเพิ่มรายการในเมนูแอปพลิเคชัน
```

## ข้อจำกัดที่ทราบ

- **การแสดงซ้อนจะไม่ปรากฏในโหมดเกมของ Steam Deck (gamescope)** บน Steam Deck แนะนำให้ใช้ปลั๊กอิน Decky ของ MAKO แทน
- เกมที่รันแบบเต็มจอเฉพาะ (exclusive fullscreen) บน Wayland แบบเนทีฟอาจบังการแสดงซ้อน
- การเปลี่ยนตัวเลือกการเปิดเกมแบบทันทีใช้ได้เฉพาะผ่านพอร์ตไคลเอนต์ Steam ที่ Decky Loader เปิดไว้ (8080) ถ้าไม่มี Decky ให้ปิด Steam ก่อนใช้การเปลี่ยนแปลง หรือให้เครื่องมือปิดและเปิด Steam ใหม่ให้
- การแสดงฟีเจอร์ที่ใช้งานจริงและเมทาดาทาโปรไฟล์ของ MAKO อ่านตามรูปแบบของ MAKO เวอร์ชันปัจจุบัน หลังอัปเดต MAKO หรือ Steam ครั้งใหญ่ อาจแสดงไม่ได้ชั่วคราว (จะเห็น "—") แต่การติดตั้งและถอดออกยังใช้ได้ตามปกติ
- ในภาษาไทย เวียดนาม มาเลย์ และฮินดี เมนูคลิกขวาจะเป็นภาษาอังกฤษ (Qt ไม่มีคำแปลอย่างเป็นทางการสำหรับภาษาเหล่านี้) Steam ไม่มีชื่อเกมภาษามาเลย์และฮินดี สองภาษานี้จึงแสดงชื่อเกมต้นฉบับเสมอ
- เก็บไฟล์สำรองไว้เฉพาะชุดล่าสุดเท่านั้น

| `~/.config/mako-assistant/state.json` | สถานะของผู้ช่วย MAKO เอง: แคชรายการเกม, เกมที่ติดตั้งผ่านเครื่องมือนี้, ภาษาหน้าจอ, การตั้งค่าการแสดงซ้อน |
| `~/.config/mako-render/conf.toml` | การตั้งค่าของ MAKO Renderer (โปรไฟล์ของแต่ละเกม) |
| `~/.config/mako-render/profile-metadata.json` | เมทาดาทาโปรไฟล์ของ MAKO (ชื่อเกม, Steam App ID) |
| `<Steam>/userdata/<ID ผู้ใช้>/config/localconfig.vdf` | ตัวเลือกการเปิดเกมของ Steam |
