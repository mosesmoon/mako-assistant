## English

> ⚠ MAKO Assistant does not include MAKO Renderer. Install MAKO Renderer yourself and open MAKO UI once before using it. See the feature guide `docs/features/en.md` for details.

### New

- **Single-file installer**: `MAKO_Assistant-1.1.1-x86_64.bin` installs MAKO Assistant for your user account, with an application menu entry and the `mako-assistant` command. No root needed; run it again to upgrade, or with `--uninstall` to remove it.
- **Flatpak package**: install `MAKO_Assistant-1.1.1-x86_64.flatpak` with `flatpak install --user`; the KDE runtime is downloaded from Flathub automatically. To manage Steam and MAKO, the Flatpak needs access to all files and runs mako-cli, Steam and the running-game check on the host through `flatpak-spawn --host`.

### Improvements

- Every version (AppImage, installer, Flatpak) uses the same settings in `~/.config`, so you can switch between them without setting anything up again.

### How to upgrade

1. AppImage: close the old MAKO Assistant and start `MAKO_Assistant-1.1.1-x86_64.AppImage` instead.
2. Prefer an installed app? Run `sh MAKO_Assistant-1.1.1-x86_64.bin` or `flatpak install --user MAKO_Assistant-1.1.1-x86_64.flatpak`. Your settings and installed games carry over automatically.

## Tiếng Việt

> ⚠ Trợ lý MAKO không kèm theo MAKO Renderer. Hãy tự cài MAKO Renderer và mở MAKO UI một lần trước khi dùng. Xem chi tiết trong tài liệu giới thiệu tính năng `docs/features/vi.md`.

### Mới

- **Trình cài đặt một tệp**: `MAKO_Assistant-1.1.1-x86_64.bin` cài Trợ lý MAKO cho tài khoản người dùng của bạn, kèm mục trong menu ứng dụng và lệnh `mako-assistant`. Không cần root; chạy lại để cập nhật, hoặc thêm `--uninstall` để gỡ bỏ.

Để quản lý Steam và MAKO, bản Flatpak cần quyền truy cập mọi tệp và chạy mako-cli, Steam cùng việc phát hiện game đang chạy trên máy chủ thông qua `flatpak-spawn --host`.

- Mọi phiên bản (AppImage, trình cài đặt, Flatpak) đều dùng chung cấu hình trong `~/.config`, nên có thể chuyển qua lại mà không cần thiết lập lại.

1. AppImage: đóng Trợ lý MAKO bản cũ và mở `MAKO_Assistant-1.1.1-x86_64.AppImage` thay thế.

## Bahasa Melayu

> ⚠ Pembantu MAKO tidak termasuk MAKO Renderer. Pasang MAKO Renderer sendiri dan buka MAKO UI sekali sebelum menggunakannya. Lihat pengenalan ciri `docs/features/ms.md` untuk butiran.

### Baharu

- **Pemasang satu fail**: `MAKO_Assistant-1.1.1-x86_64.bin` memasang Pembantu MAKO untuk akaun pengguna anda, bersama entri dalam menu aplikasi dan arahan `mako-assistant`. Tidak perlu root; jalankan sekali lagi untuk menaik taraf, atau dengan `--uninstall` untuk membuangnya.
- **Pakej Flatpak**: pasang `MAKO_Assistant-1.1.1-x86_64.flatpak` dengan `flatpak install --user`; persekitaran KDE dimuat turun secara automatik dari Flathub. Untuk mengurus Steam dan MAKO, versi Flatpak memerlukan akses kepada semua fail dan menjalankan mako-cli, Steam serta pengesanan permainan yang sedang berjalan pada sistem hos melalui `flatpak-spawn --host`.

### Penambahbaikan

- Semua versi (AppImage, pemasang, Flatpak) menggunakan tetapan yang sama dalam `~/.config`, jadi anda boleh bertukar antara versi tanpa menetapkan semula apa-apa.

### Cara menaik taraf

1. AppImage: tutup Pembantu MAKO versi lama dan buka `MAKO_Assistant-1.1.1-x86_64.AppImage` sebagai ganti.
2. Lebih suka aplikasi yang dipasang? Jalankan `sh MAKO_Assistant-1.1.1-x86_64.bin` atau `flatpak install --user MAKO_Assistant-1.1.1-x86_64.flatpak`. Tetapan dan permainan yang sudah dipasang akan dikekalkan secara automatik.

## हिन्दी

> ⚠ MAKO सहायक में MAKO Renderer शामिल नहीं है। इस्तेमाल से पहले MAKO Renderer ख़ुद इंस्टॉल करें और MAKO UI को एक बार खोलें। विवरण के लिए सुविधाओं का परिचय `docs/features/hi.md` देखें।

### नया

- **एक-फ़ाइल इंस्टॉलर**: `MAKO_Assistant-1.1.1-x86_64.bin` MAKO सहायक को आपके उपयोगकर्ता खाते के लिए इंस्टॉल करता है, साथ में ऐप्लिकेशन मेनू की प्रविष्टि और `mako-assistant` कमांड भी बनाता है। root की ज़रूरत नहीं; अपडेट के लिए इसे फिर से चलाएँ, या हटाने के लिए `--uninstall` के साथ चलाएँ।
- **Flatpak पैकेज**: `MAKO_Assistant-1.1.1-x86_64.flatpak` को `flatpak install --user` से इंस्टॉल करें; KDE रनटाइम Flathub से अपने-आप डाउनलोड होता है। Steam और MAKO को संभालने के लिए Flatpak संस्करण को सभी फ़ाइलों तक पहुँच चाहिए, और यह mako-cli, Steam तथा चल रहे गेम की पहचान को `flatpak-spawn --host` के ज़रिए होस्ट सिस्टम पर चलाता है।

### सुधार

- सभी संस्करण (AppImage, इंस्टॉलर, Flatpak) `~/.config` की एक ही सेटिंग्स इस्तेमाल करते हैं, इसलिए आप दोबारा कुछ सेट किए बिना इनके बीच बदल सकते हैं।

### अपडेट कैसे करें

1. AppImage: पुराना MAKO सहायक बंद करें और उसकी जगह `MAKO_Assistant-1.1.1-x86_64.AppImage` चलाएँ।
2. इंस्टॉल किया हुआ ऐप चाहिए? `sh MAKO_Assistant-1.1.1-x86_64.bin` या `flatpak install --user MAKO_Assistant-1.1.1-x86_64.flatpak` चलाएँ। आपकी सेटिंग्स और इंस्टॉल किए गए गेम अपने-आप बने रहते हैं।
