## English

> ⚠ MAKO Assistant does not include MAKO Renderer. Install MAKO Renderer yourself and open MAKO UI once before using it. See the feature guide `docs/features/en.md` for details.

### New

- **Single-file installer**: `MAKO_Assistant-1.2.0-x86_64.bin` installs MAKO Assistant for your user account, with an application menu entry and the `mako-assistant` command. No root needed; run it again to upgrade, or with `--uninstall` to remove it.
- **Flatpak package**: install `MAKO_Assistant-1.2.0-x86_64.flatpak` with `flatpak install --user`; the KDE runtime is downloaded from Flathub automatically. To manage Steam and MAKO, the Flatpak needs access to all files and runs mako-cli, Steam and the running-game check on the host through `flatpak-spawn --host`.
- **MAKO Renderer 4.6 settings**: the per-game panel adds GPU Headroom (Off or 5–20% spare GPU capacity during Frame Generation), Match display refresh rate for Adaptive, and HDR quality (Quality, Balanced, Performance). They need MAKO Renderer 4.5 or 4.6; older versions ignore them.
- **Battery and AC settings**: when a game has separate settings for battery and AC power (MAKO Renderer 4.5+), pick Base settings, Handheld (Battery) or Docked (AC Power) to edit, and see which one is in use now. New game profiles copy these sets from the default profile.

### Improvements

- **Finds mako-launch automatically**: MAKO Assistant uses `~/.local/bin/mako-launch` when it exists, otherwise the one on your PATH (for example `/usr/bin/mako-launch` from the Arch package), and writes that path into the Steam launch options.
- Live MAKO features now show when Adaptive follows the display refresh rate and when GPU Headroom is on.
- Every version (AppImage, installer, Flatpak) uses the same settings in `~/.config`, so you can switch between them without setting anything up again.
- Number fields such as Target FPS no longer appear empty with newer Qt versions.

### How to upgrade

1. AppImage: close the old MAKO Assistant and start `MAKO_Assistant-1.2.0-x86_64.AppImage` instead.
2. Prefer an installed app? Run `sh MAKO_Assistant-1.2.0-x86_64.bin` or `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak`. Your settings and installed games carry over automatically.
3. The new settings were checked against MAKO Renderer 4.6's own `mako-cli validate`.

## 台灣正體中文

> ⚠ MAKO 助手不包含 MAKO Renderer。使用前請先自行安裝 MAKO Renderer，並開啟一次 MAKO UI。完整說明見功能介紹文件 `docs/features/zh_TW.md`。

### 新增

- **單一檔案安裝程式**：`MAKO_Assistant-1.2.0-x86_64.bin` 會把 MAKO 助手安裝到你的使用者帳號，並建立應用程式選單項目與 `mako-assistant` 指令。不需要 root；再執行一次即可升級，加上 `--uninstall` 則會移除。

- **MAKO Renderer 4.6 設定**：每款遊戲的設定面板新增「GPU 餘裕」（補幀時保留 5–20% 的 GPU 運算能力，或關閉）、自適應模式的「配合螢幕更新率」，以及「HDR 畫質」（畫質、平衡、效能）。這些設定需要 MAKO Renderer 4.5 或 4.6，舊版會忽略。

- **自動偵測 mako-launch**：有 `~/.local/bin/mako-launch` 就使用它，否則使用 PATH 中找到的（例如 Arch 套件安裝的 `/usr/bin/mako-launch`），並把實際路徑寫入 Steam 啟動選項。
- 「執行中的 MAKO 功能」現在會顯示自適應是否配合螢幕更新率，以及 GPU 餘裕是否開啟。
- 所有版本（AppImage、安裝程式、Flatpak）都使用 `~/.config` 中的同一份設定，可以互相切換，不必重新設定。
- 修正在較新的 Qt 版本中，目標 FPS 等數字欄位顯示成空白的問題。

### 升級方式

1. AppImage：關閉舊版 MAKO 助手，改用 `MAKO_Assistant-1.2.0-x86_64.AppImage` 開啟。
2. 想改用安裝版：執行 `sh MAKO_Assistant-1.2.0-x86_64.bin`，或 `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak`。設定與已安裝的遊戲會自動沿用。
3. 新設定都已用 MAKO Renderer 4.6 自己的 `mako-cli validate` 驗證過。

## 日本語

> ⚠ MAKO アシスタントには MAKO Renderer は含まれていません。使う前に MAKO Renderer をご自身でインストールし、MAKO UI を一度開いてください。詳しくは機能紹介 `docs/features/ja.md` をご覧ください。

### 新機能

- **単一ファイルのインストーラー**：`MAKO_Assistant-1.2.0-x86_64.bin` で MAKO アシスタントをユーザーアカウントにインストールし、アプリケーションメニューの項目と `mako-assistant` コマンドを作成します。root は不要です。もう一度実行するとアップデート、`--uninstall` を付けると削除します。

- **MAKO Renderer 4.6 の設定**：ゲームごとの設定パネルに「GPU 余力」（フレーム生成中に GPU 能力を 5〜20% 空けておく、またはオフ）、アダプティブの「ディスプレイのリフレッシュレートに合わせる」、「HDR品質」（品質・バランス・パフォーマンス）を追加しました。MAKO Renderer 4.5 または 4.6 が必要で、古いバージョンでは無視されます。
- **バッテリーと AC 電源の設定**：ゲームがバッテリーと AC 電源で別々の設定を持つ場合（MAKO Renderer 4.5 以降）、「基本設定」「ハンドヘルド（バッテリー）」「ドック（AC電源）」のどれを編集するか選べ、現在使用中の設定も表示されます。新しいゲームプロファイルは既定のプロファイルからこれらの設定もコピーします。

### 改善

- **mako-launch を自動検出**：`~/.local/bin/mako-launch` があればそれを使い、なければ PATH 上のもの（Arch パッケージの `/usr/bin/mako-launch` など）を使って、そのパスを Steam の起動オプションに書き込みます。
- 「実行中の MAKO 機能」に、アダプティブがリフレッシュレートに合わせているか、GPU 余力がオンかどうかを表示します。
- どの版（AppImage、インストーラー、Flatpak）も `~/.config` の同じ設定を使うので、設定し直さずに切り替えられます。
- 新しい Qt で目標 FPS などの数値欄が空白に見える問題を修正しました。

### アップデート方法

1. AppImage：旧バージョンの MAKO アシスタントを閉じ、`MAKO_Assistant-1.2.0-x86_64.AppImage` を起動してください。
2. インストール版を使う場合は `sh MAKO_Assistant-1.2.0-x86_64.bin` または `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak` を実行してください。設定と導入済みのゲームはそのまま引き継がれます。
3. 新しい設定は MAKO Renderer 4.6 の `mako-cli validate` で検証済みです。

## ไทย

> ⚠ ผู้ช่วย MAKO ไม่ได้รวม MAKO Renderer มาด้วย โปรดติดตั้ง MAKO Renderer เองและเปิด MAKO UI หนึ่งครั้งก่อนใช้งาน ดูรายละเอียดได้ในเอกสารแนะนำฟีเจอร์ `docs/features/th.md`

### สิ่งใหม่

- **ตัวติดตั้งไฟล์เดียว**: `MAKO_Assistant-1.2.0-x86_64.bin` ติดตั้งผู้ช่วย MAKO ให้บัญชีผู้ใช้ของคุณ พร้อมรายการในเมนูแอปพลิเคชันและคำสั่ง `mako-assistant` ไม่ต้องใช้ root เรียกใช้อีกครั้งเพื่ออัปเดต หรือใส่ `--uninstall` เพื่อถอนการติดตั้ง
- **แพ็กเกจ Flatpak**: ติดตั้ง `MAKO_Assistant-1.2.0-x86_64.flatpak` ด้วย `flatpak install --user` ระบบจะดาวน์โหลดรันไทม์ KDE จาก Flathub ให้อัตโนมัติ เพื่อจัดการ Steam และ MAKO เวอร์ชัน Flatpak ต้องเข้าถึงไฟล์ทั้งหมด และเรียกใช้ mako-cli, Steam และการตรวจจับเกมที่กำลังเล่นบนเครื่องหลักผ่าน `flatpak-spawn --host`
- **การตั้งค่าของ MAKO Renderer 4.6**: แผงการตั้งค่าของแต่ละเกมเพิ่ม "ส่วนเผื่อ GPU" (ปิด หรือเหลือกำลัง GPU 5–20% ระหว่างสร้างเฟรม), "ตามอัตรารีเฟรชของจอ" สำหรับโหมดปรับตัว และ "คุณภาพ HDR" (คุณภาพ, สมดุล, ประสิทธิภาพ) ต้องใช้ MAKO Renderer 4.5 หรือ 4.6 เวอร์ชันเก่าจะไม่สนใจค่าเหล่านี้
- **การตั้งค่าแยกสำหรับแบตเตอรี่และไฟบ้าน**: เมื่อเกมมีการตั้งค่าแยกสำหรับแบตเตอรี่และไฟบ้าน (MAKO Renderer 4.5 ขึ้นไป) เลือกได้ว่าจะแก้ไข "การตั้งค่าพื้นฐาน", "พกพา (แบตเตอรี่)" หรือ "ต่อแท่น (ไฟบ้าน)" และดูได้ว่าตอนนี้ใช้ชุดไหน โปรไฟล์เกมใหม่จะคัดลอกชุดการตั้งค่าเหล่านี้จากโปรไฟล์เริ่มต้นด้วย

### การปรับปรุง

- **ค้นหา mako-launch อัตโนมัติ**: ถ้ามี `~/.local/bin/mako-launch` จะใช้ตัวนั้น ไม่เช่นนั้นจะใช้ตัวที่อยู่ใน PATH (เช่น `/usr/bin/mako-launch` จากแพ็กเกจ Arch) และเขียนพาธนั้นลงในตัวเลือกการเปิดเกมของ Steam
- "ฟีเจอร์ MAKO ที่ทำงานอยู่" จะแสดงว่าโหมดปรับตัวใช้อัตรารีเฟรชของจอหรือไม่ และเปิดส่วนเผื่อ GPU อยู่หรือไม่
- ทุกเวอร์ชัน (AppImage, ตัวติดตั้ง, Flatpak) ใช้การตั้งค่าชุดเดียวกันใน `~/.config` จึงสลับกันได้โดยไม่ต้องตั้งค่าใหม่
- แก้ปัญหาช่องตัวเลข เช่น FPS เป้าหมาย แสดงเป็นช่องว่างใน Qt เวอร์ชันใหม่

### วิธีอัปเดต

1. AppImage: ปิดผู้ช่วย MAKO เวอร์ชันเก่า แล้วเปิด `MAKO_Assistant-1.2.0-x86_64.AppImage` แทน
2. ถ้าต้องการแบบติดตั้ง ให้เรียกใช้ `sh MAKO_Assistant-1.2.0-x86_64.bin` หรือ `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak` การตั้งค่าและเกมที่ติดตั้งไว้จะใช้ต่อได้อัตโนมัติ
3. ตรวจสอบการตั้งค่าใหม่ด้วย `mako-cli validate` ของ MAKO Renderer 4.6 แล้ว

## Tiếng Việt

> ⚠ Trợ lý MAKO không kèm theo MAKO Renderer. Hãy tự cài MAKO Renderer và mở MAKO UI một lần trước khi dùng. Xem chi tiết trong tài liệu giới thiệu tính năng `docs/features/vi.md`.

### Mới

- **Trình cài đặt một tệp**: `MAKO_Assistant-1.2.0-x86_64.bin` cài Trợ lý MAKO cho tài khoản người dùng của bạn, kèm mục trong menu ứng dụng và lệnh `mako-assistant`. Không cần root; chạy lại để cập nhật, hoặc thêm `--uninstall` để gỡ bỏ.
- **Gói Flatpak**: cài `MAKO_Assistant-1.2.0-x86_64.flatpak` bằng `flatpak install --user`; môi trường KDE được tải tự động từ Flathub. Để quản lý Steam và MAKO, bản Flatpak cần quyền truy cập mọi tệp và chạy mako-cli, Steam cùng việc phát hiện game đang chạy trên máy chủ thông qua `flatpak-spawn --host`.
- **Thiết lập của MAKO Renderer 4.6**: bảng thiết lập của từng game có thêm Dự phòng GPU (tắt hoặc chừa 5–20% sức GPU khi tạo khung hình), "Theo tần số quét của màn hình" cho chế độ thích ứng và Chất lượng HDR (Chất lượng, Cân bằng, Hiệu năng). Cần MAKO Renderer 4.5 hoặc 4.6; bản cũ sẽ bỏ qua các thiết lập này.
- **Thiết lập khi dùng pin và khi cắm điện**: khi game có thiết lập riêng cho pin và cắm điện (MAKO Renderer 4.5 trở lên), có thể chọn chỉnh Thiết lập cơ bản, Cầm tay (pin) hoặc Gắn đế (cắm điện) và xem bộ nào đang được dùng. Hồ sơ game mới sẽ sao chép các bộ thiết lập này từ hồ sơ mặc định.

### Cải tiến

- **Tự tìm mako-launch**: Trợ lý MAKO dùng `~/.local/bin/mako-launch` nếu có, nếu không thì dùng bản trong PATH (ví dụ `/usr/bin/mako-launch` từ gói Arch), và ghi đúng đường dẫn đó vào tùy chọn khởi chạy của Steam.
- Phần tính năng MAKO đang hoạt động giờ cho biết chế độ thích ứng có theo tần số quét màn hình không và Dự phòng GPU có đang bật không.
- Mọi phiên bản (AppImage, trình cài đặt, Flatpak) đều dùng chung cấu hình trong `~/.config`, nên có thể chuyển qua lại mà không cần thiết lập lại.
- Các ô số như FPS mục tiêu không còn hiện trống với các phiên bản Qt mới.

### Cách cập nhật

1. AppImage: đóng Trợ lý MAKO bản cũ và mở `MAKO_Assistant-1.2.0-x86_64.AppImage` thay thế.
2. Muốn dùng bản cài đặt? Chạy `sh MAKO_Assistant-1.2.0-x86_64.bin` hoặc `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak`. Cấu hình và các game đã cài được giữ nguyên tự động.
3. Các thiết lập mới đã được kiểm tra bằng `mako-cli validate` của MAKO Renderer 4.6.

## Bahasa Melayu

> ⚠ Pembantu MAKO tidak termasuk MAKO Renderer. Pasang MAKO Renderer sendiri dan buka MAKO UI sekali sebelum menggunakannya. Lihat pengenalan ciri `docs/features/ms.md` untuk butiran.

### Baharu

- **Pemasang satu fail**: `MAKO_Assistant-1.2.0-x86_64.bin` memasang Pembantu MAKO untuk akaun pengguna anda, bersama entri dalam menu aplikasi dan arahan `mako-assistant`. Tidak perlu root; jalankan sekali lagi untuk menaik taraf, atau dengan `--uninstall` untuk membuangnya.
- **Pakej Flatpak**: pasang `MAKO_Assistant-1.2.0-x86_64.flatpak` dengan `flatpak install --user`; persekitaran KDE dimuat turun secara automatik dari Flathub. Untuk mengurus Steam dan MAKO, versi Flatpak memerlukan akses kepada semua fail dan menjalankan mako-cli, Steam serta pengesanan permainan yang sedang berjalan pada sistem hos melalui `flatpak-spawn --host`.
- **Tetapan MAKO Renderer 4.6**: panel tetapan setiap permainan kini ada Ruang GPU (mati atau 5–20% kapasiti GPU kosong semasa penjanaan bingkai), "Ikut kadar segar semula paparan" untuk mod adaptif dan Kualiti HDR (Kualiti, Seimbang, Prestasi). Ia memerlukan MAKO Renderer 4.5 atau 4.6; versi lama mengabaikannya.
- **Tetapan bateri dan kuasa AU**: apabila permainan mempunyai tetapan berasingan untuk bateri dan kuasa AU (MAKO Renderer 4.5+), pilih untuk menyunting Tetapan asas, Pegang tangan (bateri) atau Dok (kuasa AU), dan lihat set yang sedang digunakan. Profil permainan baharu menyalin set ini daripada profil lalai.

### Penambahbaikan

- **Mencari mako-launch secara automatik**: Pembantu MAKO menggunakan `~/.local/bin/mako-launch` jika ada, jika tidak yang dalam PATH (contohnya `/usr/bin/mako-launch` daripada pakej Arch), dan menulis laluan itu ke dalam pilihan pelancaran Steam.
- Ciri MAKO yang aktif kini menunjukkan sama ada mod adaptif mengikut kadar segar semula paparan dan sama ada Ruang GPU dihidupkan.
- Semua versi (AppImage, pemasang, Flatpak) menggunakan tetapan yang sama dalam `~/.config`, jadi anda boleh bertukar antara versi tanpa menetapkan semula apa-apa.
- Medan nombor seperti FPS sasaran tidak lagi kelihatan kosong dengan versi Qt yang lebih baharu.

### Cara menaik taraf

1. AppImage: tutup Pembantu MAKO versi lama dan buka `MAKO_Assistant-1.2.0-x86_64.AppImage` sebagai ganti.
2. Lebih suka aplikasi yang dipasang? Jalankan `sh MAKO_Assistant-1.2.0-x86_64.bin` atau `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak`. Tetapan dan permainan yang sudah dipasang akan dikekalkan secara automatik.
3. Tetapan baharu telah disemak dengan `mako-cli validate` daripada MAKO Renderer 4.6.

## हिन्दी

> ⚠ MAKO सहायक में MAKO Renderer शामिल नहीं है। इस्तेमाल से पहले MAKO Renderer ख़ुद इंस्टॉल करें और MAKO UI को एक बार खोलें। विवरण के लिए सुविधाओं का परिचय `docs/features/hi.md` देखें।

### नया

- **एक-फ़ाइल इंस्टॉलर**: `MAKO_Assistant-1.2.0-x86_64.bin` MAKO सहायक को आपके उपयोगकर्ता खाते के लिए इंस्टॉल करता है, साथ में ऐप्लिकेशन मेनू की प्रविष्टि और `mako-assistant` कमांड भी बनाता है। root की ज़रूरत नहीं; अपडेट के लिए इसे फिर से चलाएँ, या हटाने के लिए `--uninstall` के साथ चलाएँ।
- **Flatpak पैकेज**: `MAKO_Assistant-1.2.0-x86_64.flatpak` को `flatpak install --user` से इंस्टॉल करें; KDE रनटाइम Flathub से अपने-आप डाउनलोड होता है। Steam और MAKO को संभालने के लिए Flatpak संस्करण को सभी फ़ाइलों तक पहुँच चाहिए, और यह mako-cli, Steam तथा चल रहे गेम की पहचान को `flatpak-spawn --host` के ज़रिए होस्ट सिस्टम पर चलाता है।
- **MAKO Renderer 4.6 की सेटिंग्स**: हर गेम के सेटिंग्स पैनल में अब GPU हेडरूम (बंद, या फ़्रेम जनरेशन के दौरान GPU की 5–20% क्षमता खाली), अनुकूली मोड के लिए "डिस्प्ले रिफ़्रेश रेट से मिलाएँ" और HDR गुणवत्ता (गुणवत्ता, संतुलित, परफ़ॉर्मेंस) हैं। इनके लिए MAKO Renderer 4.5 या 4.6 चाहिए; पुराने संस्करण इन्हें अनदेखा करते हैं।
- **बैटरी और AC पावर की सेटिंग्स**: जब किसी गेम में बैटरी और AC पावर के लिए अलग सेटिंग्स हों (MAKO Renderer 4.5+), तो मूल सेटिंग्स, हैंडहेल्ड (बैटरी) या डॉक (AC पावर) में से किसे संपादित करना है चुनें, और देखें कि अभी कौन-सा सेट इस्तेमाल हो रहा है। नए गेम प्रोफ़ाइल ये सेट डिफ़ॉल्ट प्रोफ़ाइल से कॉपी करते हैं।

### सुधार

- **mako-launch अपने-आप ढूँढता है**: MAKO सहायक `~/.local/bin/mako-launch` मौजूद होने पर उसे, वरना PATH वाले को (जैसे Arch पैकेज का `/usr/bin/mako-launch`) इस्तेमाल करता है, और वही पाथ Steam लॉन्च विकल्पों में लिखता है।
- सक्रिय MAKO सुविधाएँ अब बताती हैं कि अनुकूली मोड डिस्प्ले रिफ़्रेश रेट के साथ चल रहा है या नहीं, और GPU हेडरूम चालू है या नहीं।
- सभी संस्करण (AppImage, इंस्टॉलर, Flatpak) `~/.config` की एक ही सेटिंग्स इस्तेमाल करते हैं, इसलिए आप दोबारा कुछ सेट किए बिना इनके बीच बदल सकते हैं।
- नए Qt संस्करणों में लक्ष्य FPS जैसे संख्या वाले फ़ील्ड अब खाली नहीं दिखते।

### अपडेट कैसे करें

1. AppImage: पुराना MAKO सहायक बंद करें और उसकी जगह `MAKO_Assistant-1.2.0-x86_64.AppImage` चलाएँ।
2. इंस्टॉल किया हुआ ऐप चाहिए? `sh MAKO_Assistant-1.2.0-x86_64.bin` या `flatpak install --user MAKO_Assistant-1.2.0-x86_64.flatpak` चलाएँ। आपकी सेटिंग्स और इंस्टॉल किए गए गेम अपने-आप बने रहते हैं।
3. नई सेटिंग्स को MAKO Renderer 4.6 के अपने `mako-cli validate` से जाँचा गया है।
