## English

> ⚠ MAKO Assistant does not include MAKO Renderer. Install MAKO Renderer yourself and open MAKO UI once before using it. See the feature guide `docs/features/en.md` for details.

### New

- **MAKO Renderer 5.0 support**: choose the Frame Generation model for each game (MAKO FG, LSFG Quality or LSFG Performance), also separately for battery and AC power; set the MAKO FG mode (Quality, Balanced, Performance, Extra Performance); and turn on Mailbox presentation for games that hang with Frame Generation.
- Live MAKO features show which model is running (MAKO FG or LSFG).

### Improvements

- **New wording**: MAKO FG is now the name of MAKO's own frame generation model, so the per-game switch is called "Enable MAKO" (formerly "Install Mako FG"), with matching status and filters.
- Settings a profile has not saved show MAKO Renderer 5.0's defaults (MAKO FG model, MAKO Scaler), and the Ultra Performance description covers both models.

### How to upgrade

1. AppImage: close the old MAKO Assistant and start `MAKO_Assistant-1.3.0-x86_64.AppImage` instead.
2. Prefer an installed app? Run `sh MAKO_Assistant-1.3.0-x86_64.bin` or `flatpak install --user MAKO_Assistant-1.3.0-x86_64.flatpak`. Your settings and installed games carry over automatically.
3. With MAKO Renderer 4.x the new options are ignored; update MAKO Renderer to 5.0 to use them. They were checked with MAKO Renderer 5.0's own `mako-cli validate`.

- सक्रिय MAKO सुविधाएँ दिखाती हैं कि कौन-सा मॉडल चल रहा है (MAKO FG या LSFG)।

### सुधार

- **नया नाम**: MAKO FG अब MAKO के अपने फ़्रेम जनरेशन मॉडल का नाम है, इसलिए हर गेम का स्विच अब "MAKO चालू करें" कहलाता है (पहले "Mako FG इंस्टॉल करें"); स्थिति और फ़िल्टर भी उसी के अनुसार बदले गए हैं।
- प्रोफ़ाइल में सहेजी न गई सेटिंग्स MAKO Renderer 5.0 के डिफ़ॉल्ट दिखाती हैं (MAKO FG मॉडल, MAKO Scaler), और Ultra Performance का विवरण दोनों मॉडल पर लागू है।

### अपडेट कैसे करें

1. AppImage: पुराना MAKO सहायक बंद करें और उसकी जगह `MAKO_Assistant-1.3.0-x86_64.AppImage` चलाएँ।
2. इंस्टॉल किया हुआ ऐप चाहिए? `sh MAKO_Assistant-1.3.0-x86_64.bin` या `flatpak install --user MAKO_Assistant-1.3.0-x86_64.flatpak` चलाएँ। आपकी सेटिंग्स और इंस्टॉल किए गए गेम अपने-आप बने रहते हैं।
3. MAKO Renderer 4.x के साथ नए विकल्प अनदेखे होते हैं; इन्हें इस्तेमाल करने के लिए MAKO Renderer को 5.0 पर अपडेट करें। इन्हें MAKO Renderer 5.0 के `mako-cli validate` से जाँचा गया है।
